## Description du projet

AfriConnect Summit est un site vitrine moderne conçu pour promouvoir une conférence technologique panafricaine fictive réunissant des développeurs, entrepreneurs, investisseurs et passionnés du numérique venus de différents pays d'Afrique.

## Technologies utilisées

- HTML5: sémantique (header, nav, main, section, article, footer)
- CSS3 : variables CSS, Flexbox, CSS Grid, media queries responsive (mobile / tablette / desktop), transitions et animations
- JavaScript: vanilla (aucune librairie ni framework)
- Google Fonts : Space Grotesk (titres) et Poppins (texte courant)
- Bootstrap Icons (via CDN) pour les icônes

## Fonctionnalités JavaScript implémentées

- Mode sombre / clair avec sauvegarde de la préférence dans localStorage
- Navbar dynamique (changement de style au défilement) + menu hamburger mobile
- Animations d'apparition des sections au scroll via IntersectionObserver
- Compteurs animés (chiffres clés) déclenchés au scroll
- Compte à rebours en temps réel jusqu'à la date de la conférence
- Onglets du programme (affichage du planning par jour, sans rechargement de page)
- Filtrage dynamique des intervenants par thématique
- Validation complète du formulaire d'inscription (champs requis, regex email, longueur minimale du téléphone et du message) avec retour visuel par champ
- Bouton de retour en haut de page avec défilement fluide
- Année dynamique dans le pied de page
